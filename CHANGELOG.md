# Changelog

All notable changes to Helix are documented here.

## 1.0.1 - 2026-10-21

- Updated Astro to 7.4.1 and other dependencies.
- Updated `AGENTS.md` for Astro 7.
- Files check out with LF line endings on every platform.
- Fixed the theme name in the license title.

## 1.0.0 - 2026-07-28

- Initial commercial release.
- Astro 7 science-publication theme with static home, article, category, tag, author, All Stories, search, about, contact, privacy, editorial standards, changelog, RSS, robots, sitemap, and 404 routes.
- Evidence-forward editorial identity with research-status labels, key findings, methodology notes, source lists, author bios, and science-focused category metadata.
- Full-bleed homepage lead story, briefing columns, category image slider, Field Notes feature, paired Earth/Space and Life/Health sections, Physics/Technology coverage, newsletter band, and latest-story list.
- Sticky masthead with desktop category navigation, accessible mobile drawer, dialog search, and transparent variants for visual lead pages.
- Lightweight static search with lazy header index loading, fallback results, standalone search page, and no external search service.
- Typed content collections, draft handling, centralized category and publication configuration, image metadata, and reusable post helpers.
- Canonical URLs, Open Graph and Twitter/X metadata, Article and WebSite JSON-LD, sitemap generation, RSS, and configurable production URLs.
- Self-hosted fonts with no third-party font request.
- Local Bootstrap icons with their license notice.
- Provider-neutral newsletter and contact forms, starter editorial/legal pages, and Markdown-only article content.
- Accessible landmarks, heading structure, labels, skip navigation, visible focus states, keyboard-friendly drawer/search behavior, print styles, reduced-motion handling, and progressive enhancement.
- Astro-aware Prettier release check and updated dependencies to patched release versions.
